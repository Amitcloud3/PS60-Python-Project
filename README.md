# Employee Leave Management System (PS No. 60)

A simple console-based Python application developed for B.Tech First Semester coursework (Rungta International Skills University). 

## Features
- **Apply for Leave:** Validates employee ID, leave type (Casual, Sick, Earned), date format (`YYYY-MM-DD`), and inclusive day count.
- **Balance Check & Approval:** Automatically approves or rejects leave requests based on available balance and updates records.
- **View Balance:** Displays remaining leave balances for an employee.

## Concepts Used
- Nested Dictionaries
- User-defined Functions
- Conditional Statements & Input Validation
- Python `datetime` module
